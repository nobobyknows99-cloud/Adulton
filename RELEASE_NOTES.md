# Release notes and new features

This update expands Adulton with:

- Title screen and main menu with looping music
- Custom main menu screen and basic menu buttons
- CG placeholders and image declarations
- More characters and deeper route structure with epilogues
- Screens for save/load integration and CG preview support

How to use:
- Add your PNG files into game/images/ using the filenames in game/images/ASSETS_README.txt
- Add menu_theme.ogg into game/audio/ if you want music
- Launch the project in the Ren'Py launcher
