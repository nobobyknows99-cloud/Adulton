# Adulton

Adulton is a complete Ren'Py adult visual novel starter with:

- age verification screen
- adult content gating behind the age check
- branching romance routes
- multiple endings
- polished start menu and simple GUI
- fully editable script for expansion

This project is intended for adults only and is designed for mature romance storytelling. The content in the included starter uses romantic tension, sensuality, and emotional intimacy without explicit sexual scenes.

## Requirements

- Ren'Py 8.x or later
- Windows, macOS, or Linux

## Run locally

1. Install Ren'Py.
2. Extract the project folder.
3. Open the extracted folder and launch the Ren'Py project.
4. If you use the Ren'Py launcher, add the project folder as a new game.
5. Start the game from the launcher.

## Project structure

- `game/` — game scripts and GUI files
- `README.md` — project overview
- `LICENSE` — MIT license

## Notes

- The age gate appears before the story begins.
- Adult content is only unlocked after the player confirms they are 18+.
- You can extend the story by editing `game/script.rpy`.
- The provided starter is non-explicit and intentionally suitable for a mature romance VN while staying within safer, non-graphic boundaries.
