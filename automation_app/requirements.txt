# Python automation app starter

This app organizes files in a folder by extension and logs everything.

## Example

- `Pictures/` -> `Images/`
- `notes.txt` -> `Text/`
- `script.py` -> `Code/`

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
