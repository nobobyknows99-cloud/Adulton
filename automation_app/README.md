# Automation App Starter

A small Python desktop automation app for organizing files and automating repetitive tasks.

Features:
- Select a source folder
- Choose whether to copy or move files
- Organize files into folders by file type
- View a live log window
- Open the destination folder after completion

## Requirements

Python 3.10+

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```
